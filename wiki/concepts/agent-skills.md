# Agent Skills

## 요약
Agent skills는 AI 에이전트가 특정 작업을 수행할 때 따를 절차, 체크리스트, 산출물 형식을 패키징한 재사용 단위다.
기존 프롬프트 조각과 다른 점은 단순 지시문이 아니라 PRD 작성, TDD, 코드 리뷰, 문서 편집처럼 반복되는 엔지니어링 프로세스를 실행 규칙으로 만든다는 것이다.
개발자에게는 모델에게 매번 긴 작업 방식을 설명하지 않고도 팀의 품질 기준과 작업 순서를 일관되게 적용하는 방법이 된다.
특히 코딩 에이전트가 커밋 전 계획, 테스트, 리뷰 같은 경계를 건너뛰지 않게 하는 가드레일 역할을 할 수 있다.

## 왜 중요한가
AI 코딩의 품질 차이는 "무엇을 만들지"보다 "어떤 절차로 만들지"에서 크게 벌어진다. skills는 그 절차를 버전 관리 가능한 개발 자산으로 바꾼다.
