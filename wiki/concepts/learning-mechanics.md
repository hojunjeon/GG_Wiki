# Learning Mechanics

## 요약
Learning mechanics는 딥러닝을 개별 아키텍처의 경험적 성공담이 아니라 학습 과정의 동역학, 거시 통계, 보편 현상으로 설명하려는 이론적 관점이다.
기존 통계학·정보이론 관점과 달리 실제 신경망 학습 중 나타나는 loss, 표현, 가중치, 하이퍼파라미터 효과를 정량적으로 예측하려는 데 초점이 있다.
개발자에게는 모델 학습을 무작정 sweep하는 대신 어떤 현상이 스케일 변화에도 반복되는지, 어떤 튜닝 변수가 시스템을 단순화하는지 판단하는 언어를 제공한다.
아직 완성된 이론이라기보다 딥러닝 이론 연구를 묶는 프로그램에 가깝다.

## 왜 중요한가
모델 규모와 학습 비용이 커질수록 시행착오 기반 튜닝은 비싸진다. learning mechanics는 학습 안정성과 성능 스케일링을 예측 가능한 엔지니어링 문제로 바꾸려는 방향이다.
