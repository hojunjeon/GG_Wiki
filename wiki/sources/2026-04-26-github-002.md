# Alishahryar1/free-claude-code

## 요약
free-claude-code는 Claude Code가 보내는 Anthropic API 호출을 NVIDIA NIM, OpenRouter, DeepSeek, LM Studio, llama.cpp, Ollama 등으로 라우팅하는 호환 프록시다.
새로운 점은 Claude Code 자체를 수정하지 않고 `ANTHROPIC_BASE_URL` 같은 환경 변수만 바꿔 여러 백엔드 모델을 섞어 쓰도록 만든 점이다.
개발자에게는 비용, 속도, 프라이버시 요구에 따라 클라우드 무료 티어와 로컬 모델을 전환하면서 같은 Claude Code UX를 유지할 수 있다는 의미가 있다.
다만 도구 호출 파싱, thinking 블록 변환, provider별 호환성은 프록시가 재해석하는 계층이므로 실제 업무 투입 전에는 모델별 실패 모드를 확인해야 한다.

## 왜 중요한가
AI 개발 도구가 특정 모델 공급자에 묶이는 문제를 줄인다. Anthropic 호환 API 프록시는 기존 CLI 경험을 유지하면서 비용·프라이버시·가용성 요구에 맞춘 백엔드 선택지를 늘린다.
