# firma: Claude를 내 포트폴리오 AI 비서로 만드는 로컬 퍼스트 자산관리 CLI

## 요약
firma는 포트폴리오 거래 기록과 잔고를 로컬 SQLite에 저장하고, CLI와 MCP 서버를 통해 Claude Desktop이 해당 데이터를 직접 조회·입력하게 하는 자산관리 도구다.
새로운 점은 투자 앱을 클라우드 대시보드로 만들지 않고, 로컬 데이터베이스와 LLM 도구 호출을 결합해 개인 금융 데이터를 사용자 장비 안에 두는 설계다.
개발자에게는 `--json` CLI와 MCP를 함께 제공하면 LLM이 읽기 전용 분석뿐 아니라 기록 추가, 브리핑, 리스크 분석 같은 작업형 인터페이스가 될 수 있음을 보여준다.
FRED, Finnhub, FX, 집중도 지표를 붙인 방식은 개인 데이터와 외부 시장 데이터를 로컬에서 조합하는 에이전트 UX 패턴으로 볼 수 있다.

## 왜 중요한가
개인 데이터 기반 AI 도구의 핵심 문제는 편의성과 프라이버시의 균형이다. firma는 로컬 퍼스트 저장소와 MCP를 결합해 민감한 데이터를 외부 SaaS에 맡기지 않는 방향을 제시한다.
