# davila7/claude-code-templates

## 요약
claude-code-templates는 Claude Code용 에이전트, slash command, MCP, 설정, hook, skill을 카탈로그 형태로 탐색하고 설치하는 도구다.
새로운 점은 개별 프롬프트나 설정 파일을 복사하는 대신, 개발 스택 단위의 AI 작업 환경을 npm CLI와 웹 대시보드로 조립하게 한다는 점이다.
개발자에게는 코드 리뷰어, 테스트 생성, 보안 점검, 외부 서비스 MCP 같은 반복 구성을 프로젝트마다 빠르게 적용하고 팀 표준으로 맞출 수 있다.
다만 템플릿을 많이 붙일수록 도구 권한과 hook 부작용이 늘어나므로, 설치 후 실제 명령·MCP 권한을 검토하는 운영 절차가 필요하다.

## 왜 중요한가
AI 코딩 도구가 개인 설정에서 팀 운영 환경으로 이동하면서 구성 재현성이 중요해졌다. 템플릿 카탈로그는 에이전트·명령·MCP를 표준 개발 환경처럼 배포하려는 흐름에 있다.
