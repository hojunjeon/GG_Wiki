# abhigyanpatwari/GitNexus

## 요약
GitNexus는 코드베이스를 파일·심볼·의존성·호출 흐름·클러스터로 인덱싱해 지식 그래프로 만들고, MCP 도구로 AI 코딩 에이전트에 제공한다.
새로운 점은 LLM이 매번 그래프를 탐색하게 두는 Graph RAG가 아니라, 인덱싱 시점에 impact, context, process search 같은 고수준 응답 구조를 미리 계산한다는 점이다.
개발자에게는 에이전트가 함수 하나를 수정할 때 호출자, 테스트, 프로세스 흐름, 변경 영향 범위를 놓치는 문제를 줄이는 보조 기억 장치가 된다.
CLI+MCP는 로컬 저장소를 대상으로 동작하고, Web UI는 브라우저 WASM 기반 탐색을 제공해 일상 개발과 빠른 분석을 나눈다.

## 왜 중요한가
코딩 에이전트의 실패는 코드 검색 부족보다 관계 맥락 누락에서 자주 생긴다. GitNexus는 코드 구조를 사전에 계산한 도구 응답으로 제공해 작은 모델도 더 안정적으로 수정 범위를 판단하게 한다.
