# mini-swe-agent - 100줄짜리 AI 에이전트로 GitHub 이슈 해결 및 커맨드라인 지원

## 요약
mini-swe-agent는 코딩 에이전트의 핵심을 복잡한 도구 호출 프레임워크가 아니라 bash 실행, 선형 메시지 기록, 독립 `subprocess.run` 실행으로 축소한다.
새로운 점은 SWE-bench 계열 성능을 유지하면서도 에이전트 scaffold를 극단적으로 단순화해, 모델 능력과 환경 설계의 영향을 더 분리해서 볼 수 있게 한 것이다.
개발자에게는 로컬 CLI, 샌드박스 실행, 벤치마크, 파인튜닝/RL 데이터 수집을 같은 단순한 실행 궤적으로 다룰 수 있다는 실용적 의미가 있다.
특히 tool-calling 인터페이스 없이도 bash만으로 동작하므로, 모델 제공자와 런타임을 바꾸는 비용이 낮다.

## 왜 중요한가
기존 코딩 에이전트는 도구 계층과 상태 관리가 복잡해 디버깅과 재현이 어려웠다. mini-swe-agent는 제어 흐름을 단순화해 에이전트 실험과 실무 자동화의 기준선을 낮춘다.
