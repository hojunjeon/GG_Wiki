# mattpocock/skills

## 요약
mattpocock/skills는 AI 코딩 도구에 넣을 수 있는 작업 절차를 PRD 작성, 이슈 분해, TDD, 리팩터링 계획, 글쓰기 등 실제 엔지니어링 워크플로 단위로 패키징한다.
새로운 점은 "좋은 프롬프트 모음"보다 한 단계 더 나아가, 반복 가능한 절차와 산출물을 skill로 배포해 에이전트 행동을 팀 프로세스에 맞추려는 점이다.
개발자에게는 복잡한 작업을 매번 즉흥 프롬프트로 통제하는 대신, 검증된 단계와 체크포인트를 재사용하는 방식으로 AI 도구의 편차를 줄일 수 있다.
특히 PRD, 이슈, TDD, 리팩터링 같은 경계가 명확한 작업은 에이전트가 코드 변경 전 맥락을 구조화하는 데 직접 도움이 된다.

## 왜 중요한가
AI 코딩 도구의 병목은 모델 성능만이 아니라 작업 절차의 일관성이다. agent skills는 개발팀의 암묵적 작업 방식을 실행 가능한 프롬프트 자산으로 바꾸는 흐름에 있다.
