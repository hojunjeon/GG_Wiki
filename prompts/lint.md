# Lint 프롬프트

## 사용법
```bash
codex "$(cat prompts/lint.md)"
```

---

먼저 `AGENT.md`를 읽고 위키 구조와 규칙을 완전히 파악해라.

그 다음 아래 순서대로 Lint 작업을 수행해라.

## 작업 순서

### 1. 모든 위키 페이지 목록 수집

`wiki/` 폴더 아래 모든 `.md` 파일을 재귀적으로 나열해라.
`index.md`, `log.md`는 별도로 처리한다.

### 2. 이슈 탐지

각 페이지에 대해 아래 4가지를 점검해라.

**a. 모순 탐지**
같은 기술·개념을 다루는 페이지가 2개 이상일 때, 서로 상충하는 내용이 있는지 확인해라.

**b. 오래된 정보**
`wiki/log.md`에서 최근 14일 이내 수집된 소스와 내용이 충돌하는 기존 페이지를 찾아라.

**c. 고아 페이지**
`wiki/index.md`에 등록되지 않은 페이지를 찾아라.
다른 페이지에서 `[[링크]]`로 참조되지 않는 페이지를 찾아라.

**d. 누락된 상호참조**
같은 카테고리 내 페이지들을 비교해서 서로 연결되어야 할 것 같은데 링크가 없는 경우를 찾아라.

### 3. 이슈 보고서 출력

아래 형식으로 출력해라.

```
## Lint 결과 — YYYY-MM-DD

### 모순
- [[페이지A]] vs [[페이지B]]: {충돌 내용 요약}

### 오래된 정보
- [[페이지]]: {최신 소스와 충돌하는 내용 요약}

### 고아 페이지
- [[페이지]]: index.md 미등록 / 참조 없음

### 누락된 상호참조
- [[페이지A]] ↔ [[페이지B]]: {연결 이유}

### 요약
총 N개 이슈 발견 (모순 N, 오래된 정보 N, 고아 N, 누락 링크 N)
```

### 4. 자동 수정 (안전한 항목만)

아래 항목은 사용자 승인 없이 직접 수정해라.
- 고아 페이지를 `wiki/index.md`에 추가
- 누락된 상호참조 링크 추가

아래 항목은 수정하지 말고 보고만 해라.
- 모순 (사용자가 판단해야 함)
- 오래된 정보 (최신 소스 확인 필요)

### 5. log.md 기록

`wiki/log.md` 상단에 한 줄 추가해라.
`## [YYYY-MM-DD] lint | N개 이슈 발견, N개 자동 수정`
