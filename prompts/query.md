# Query 프롬프트

## 사용법
```bash
codex "$(cat prompts/query.md) 질문: {여기에 질문 입력}"
```

예시:
```bash
codex "$(cat prompts/query.md) 질문: 최근 LLM 에이전트 관련 주요 동향이 뭐야?"
```

---

먼저 `AGENT.md`를 읽고 위키 구조와 규칙을 완전히 파악해라.

그 다음 아래 순서대로 Query 작업을 수행해라.

## 작업 순서

### 1. 관련 페이지 탐색

`wiki/index.md`를 읽어 질문과 관련된 페이지 목록을 찾아라.
관련도 높은 페이지를 최대 5개 선택해라.

### 2. 페이지 읽기

선택한 페이지를 모두 읽어라.
페이지 안의 `[[링크]]`를 따라가며 추가 관련 페이지도 읽어라.

### 3. 답변 생성

아래 형식으로 답변해라.

```
## 답변

{답변 내용. 출처는 [[wiki/...]] 형식으로 인라인 명시}

## 참고한 페이지
- [[wiki/...]] — 관련 내용 요약
- [[wiki/...]] — 관련 내용 요약

## 불확실한 부분
{위키에 정보가 없거나 불확실한 내용 명시. 없으면 생략}
```

### 4. 신규 페이지 생성 판단

답변 과정에서 새로운 연결 관계나 통찰을 발견했다면 아래 기준으로 판단해라.

- 위키에 없는 중요 개념이 드러났다 → `wiki/concepts/`에 신규 페이지 생성 제안
- 여러 소스를 종합한 새 인사이트가 나왔다 → `wiki/synthesis/`에 저장 제안

제안만 하고, 사용자 승인 없이 파일을 생성하지 않는다.

### 5. log.md 기록

`wiki/log.md` 상단에 한 줄 추가해라.
`## [YYYY-MM-DD] query | {질문 요약}`
